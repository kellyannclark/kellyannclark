## Current Project

### SubscriptionSync

I am currently developing **SubscriptionSync**, a custom Shopify application for Little Adventures designed to support and automate the workflow behind their dress subscription program.

SubscriptionSync is being built to connect Shopify and subscription data with an internal system that manages:

- Subscriber information
- Customer dress preferences and selections
- Subscription timing and fulfillment rules
- Automated selection workflows
- Customer reminders
- Product and inventory information
- Shipment and selection history
- Daily fulfillment queues
- Shopify API and webhook integrations
- Future order and shipping automation

The application is built with **Shopify, Remix, TypeScript, React, Prisma, PostgreSQL, GraphQL, and webhooks**.

One of my favorite parts of this project has been taking a real business workflow, breaking it into individual problems, and designing software that connects those pieces into a system people can actually use.
